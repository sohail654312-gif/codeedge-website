# Codeedge.online

Production marketing website for Codeedge.

## Positioning
**One Business. One System. One Control Centre.**

Customer journey:
**Get Found → Get Contacted → Convert → Serve → Get Paid → Retain & Grow**

## Production architecture
- Multi-page, static-first website for speed and hosting simplicity
- Premium navy/electric-blue responsive design system
- Lightweight JavaScript for navigation and qualification flow
- Clear UK service-business positioning
- No fabricated testimonials, ranking guarantees, lead guarantees or fake checkout

## Main routes
- Core: Home, Business OS, How It Works, Pricing, Results, About, Contact, Resources
- Growth: Websites, Local SEO, Google Business Profile, Reputation
- Platform: AI Receptionist, CRM & Leads, WhatsApp, Bookings, Automation, Business Visibility
- Industries: Plumbers, Heating Engineers, Electricians, Builders, Roofers, Clinics
- Resources: seven initial SEO/GEO guides
- Legal: Privacy, Terms, Cookie Policy

## SEO and accessibility
- Unique page titles/descriptions/canonicals
- XML sitemap and robots.txt
- Organization, Service, Offer, Article, FAQ and Breadcrumb structured data where relevant
- Semantic page headings and visible breadcrumbs
- Keyboard focus styles and skip navigation
- Reduced-motion support
- Automated static link/metadata/JSON-LD audit
- Automated Pa11y/Axe WCAG 2 AA gate
- Automated Lighthouse performance/accessibility/best-practices/SEO gate

## Deployment
GitHub Pages is the intended static host. The repository includes a `CNAME` for:

`codeedge.online`

Production should be merged to `main` only after the Site Audit workflow is green. After publication, verify the custom domain, HTTPS, key conversion routes and live crawlability.
